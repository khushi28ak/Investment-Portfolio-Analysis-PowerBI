# Investment Portfolio Analysis Dashboard | Power BI

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze investment portfolio performance and generate meaningful financial insights.

The dashboard enables users to track investments, portfolio value, profits, ROI, sector performance, and investor behavior through dynamic visualizations and KPIs.

---

## Objectives

- Analyze investment performance
- Track portfolio growth and profitability
- Measure Return on Investment (ROI)
- Identify top-performing sectors and stocks
- Understand investor distribution and behavior

---

## Dashboard Features

### Executive Summary
- Total Investments
- Portfolio Value
- Total Profit
- ROI %

### Investment Analysis
- Investment Trends
- Monthly Investment Activity
- Portfolio Growth

### Sector Analysis
- Investments by Sector
- Sector-wise Portfolio Value
- Sector Performance Comparison

### Stock Analysis
- Top Performing Stocks
- Investment Distribution by Stock
- Profit Contribution Analysis

### Investor Analysis
- Investors by City
- Investor Participation Trends
- Regional Distribution

## Key Insights

- Portfolio generated positive returns with consistent investment growth.
- Banking and IT sectors attracted the highest investments.
- Top-performing stocks contributed significantly to overall profits.
- Investor participation was concentrated in major metropolitan cities.
- ROI analysis highlighted strong portfolio performance.
